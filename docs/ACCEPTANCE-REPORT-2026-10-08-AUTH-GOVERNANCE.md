# 认证与题库治理整合验收

日期：2026-10-08。RELEASE-READINESS-2 的认证/题库子阶段。分支：agent-lab。

已核验并整合原有题库界面和权限编辑。列表/搜索由服务端 ADMIN 保护；候选人仍通过面试业务读取题目，不进入题库治理工作区。前端统一处理当前会话 401，旧请求晚到的 401 不会删除新登录。Lab 各工作区复用同一个请求入口，失效后清理查询缓存、回到登录门；403/503 不被误当作会话过期。

题库工作区独立为组件。新增/删除成功后刷新列表并清除旧搜索；切换搜索条件时使旧响应失效；删除失败显式显示错误，来源缺失显示“来源未记录”。本阶段没有新增题目、调用 embedding/付费业务模型、导入真实用户数据或发布 Agent。
