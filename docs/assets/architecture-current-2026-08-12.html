写入一致性：题库文件与 URL 导入在返回成功前显式 flush 向量写入，确保管理员能够立即检索新内容。
导入安全：URL 导入只允许公开 HTTPS 目标，拒绝 loopback 和内网地址；无可用题目时返回明确的 400 错误。
部署边界：默认部署使用 Docker Compose；生产发布由流水线执行 Prisma migration，并配置受控的 JWT_SECRET 与 ADMIN_USER_IDS。
