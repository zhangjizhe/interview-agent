结论与后续优化

当前结论

在该 10 轮真实样本中，当前多 Agent 默认路径没有节省 Token。README 不将历史 82.6% 数据用于描述当前版本表现。

已验证能力

认证、简历 RAG、SSE、LangGraph、多轮成本累计和会话成本面板均在当前默认部署中真实运行，基准脚本与 JSON 可复跑。

优化方向

减少每轮图节点模型调用、对重复输入做更早的短路、核对语义缓存命中后是否仍触发下游节点，并为每个节点记录独立 token 归因。
