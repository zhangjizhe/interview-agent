# 个人网站接入 Agent Lab：4 分钟录屏路线

2026-11-09。范围：公开资料问答、正常发布的 Agent、既有真实模型评测报告、报告到 Run/Trace 的只读追踪。它不是完整面试训练平台或长期服务器部署验收。

## 录制前

- 使用已验收的干净源码和当前部署。不要在含数据治理等未验收修改的工作区直接重建全部服务。
- 打开个人网站与本机 Agent Lab `http://127.0.0.1:5175`，提前完成正常登录；密码、邮箱验证码、认证请求、Secret 配置和终端私有日志不入镜。
- 先做无模型的连通检查。临时隧道失联时先恢复入口，不能连续点击新问题以掩盖故障。
- 如需现场新问答，先按持久费用账本预留最多0.03CNY；现有 Agent 每次调用上限0.03CNY，公开每日准入10次。未知费用不按零计。已经完成的回答可以展示，但必须说明是已完成记录；不导入假答案或制造打字效果。
- 本路线展示既有完成报告，不需要点击“评测当前基线”“评测候选”“生成草稿候选”或“管理员发布”。

## 0:00–0:35｜项目与边界

画面：个人网站作品页，展开 interview-agent 工程实践。

讲解：“这是个人网站接入 Agent Lab 的实际应用。助手只使用公开简历、项目和文章资料，个人事实引用原文，通用技术解读单独标注。”

## 0:35–1:25｜真实问答与来源

画面：助手中输入“介绍 interview-agent 项目”，等待真实完成状态，展示项目来源与技术参考链接。

讲解：“请求先经过范围与预算检查，再进入已发布 Agent 的运行队列。完成校验后展示回答和来源。这里是完成后的核验输出，不是逐 Token 的模型流式展示。”

保留真实等待时间；剪辑等待须明确标记。若请求失败，保留原问题与请求标识，先核对运行和费用；不要用更换 UUID 或假回答掩盖失败。对话缓存会过期，不能保证数小时后仍有同一画面。

## 1:25–2:20｜正式评测报告

画面：Lab → 自进化 → 选择“公开经历与技术解读助手” → 查看已完成1.0.3报告。

讲解：“这是此前执行并持久化的报告。十个用例，每个三次实际模型调用，共三十个样本。合同断言检查输出结构、来源引用和必要事件；通过不等于所有开放问题的语义质量都已验证。”

展示 Dataset/Evaluator、版本、样本数量、费用小计与逐项证据。旧1.0.2失败报告保留，可以展示失败断言，不能把历史失败说成本轮正在失败或已被删除。

## 2:20–3:20｜报告追到实际 Run/Trace

画面：展开逐项证据，在一条 Case 下点击“查看 Run … 的运行记录与 Trace”。

讲解：“每个重复样本都能追到自己的运行记录。这里核对固定 Agent/版本、完成状态、模型调用数、估算费用和按序事件。查看是只读操作，不会重新执行模型。”

实际可见事件以该条记录为准，不承诺所有运行都有相同事件。面板不展示 Prompt、输入、输出或原始错误正文；空 Trace、未知费用、权限拒绝、版本不匹配都保留明确状态。关闭详情返回原报告，可选择另一个样本。

## 3:20–4:00｜故障与交付边界

画面：保留报告的“语义质量未评估”说明，回到网站回答与来源。

讲解：“当前已经验证这条网站到运行与报告的链路。后台仍在当前电脑，稳定域名、闲置 Mac 迁移和重启恢复还未验收。下一步是完成长期部署与更广泛的质量评估。”

## 本轮预演证据

- 源码：只读面板复用已有 ADMIN/工作区归属 GET Run 和 GET Trace，不新增数据库、发布入口或模型调用。
- 本地：8项定向组件/集成回归、完整 Web348项、Lab类型、构建、相关lint和diff通过。组件测试是合成数据，不是实际报告验收。
- 实际浏览器：正常既有登录会话 → 正式1.0.3报告 → 首个真实样本 → COMPLETED、版本1.0.3、一次历史模型调用、估算0.000616CNY、四条有序事件。此费用是该历史样本的记录，不是本轮查看产生的费用。
- 只替换本机 Lab 前端镜像，保留原镜像与回滚记录、端口和挂载；API/数据库未重启，无迁移。网站仍是 Site7/env2。
- 精确新提交的 CI/PR/远端核对在提交后单独记录；之前 PR69 的 CI 不能认证本次新前端改动。
