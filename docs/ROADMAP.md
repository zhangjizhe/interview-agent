## P2 · 成本、隔离与规模化

- **Prompt cache**：历史压测记录 0% 命中，并记录 DashScope 兼容层未识别 `prompt_cache_key`。该结论只对应当时环境，不能外推所有版本。下一步核验目标 Provider 的真实计费/缓存字段，再比较不同 Provider；不承诺更换厂商就自动生效。
- **语义缓存**：历史 50 轮未触发白名单节点，命中为 0%，原因与 prompt cache 不同。2026-08-12 基准记录 46 次命中，但总 Token 为 20,024，对照为 15,402（+30.01%）。下一步减少图节点调用，核验命中后的短路与逐节点 Token 归因。[历史基准](../README.md#多-agent-与缓存-token-基准)
- **精确缓存**：历史 Redis 基准记录 <1ms 响应；它不能代表整轮面试延迟。下一步统一负载、样本量和统计口径。
- **向量库**：Milvus 当前是单机 Compose，尚无多租户容量和灾备验证；按真实数据量与负载规划，不按未经验证的固定条数承诺容量。
- **可观测**：已有 Langfuse 采样与成本面板；10% trace 采样不等于总成本下降 90%。尚无完整 CPU/内存/慢查询 APM、Sentry 类错误聚合和 Prometheus/Grafana 运维面板。
- **隔离执行**：ToolRunner 有审批、预算与目录边界，但 command executor 不是 OS 沙箱；子 Run 尚无调度器、远程 worker 和自动重试。接入真实隔离环境后再开放不受信任执行。
- **Trace 治理**：追加式事件与导出已实现，归档、脱敏清理及对象存储 payload 引用仍待补齐；独立 Run 成本尚不可用。
- **部署与展示**：保留历史截图，录制新的候选人全流程；静态演示须明确标注模拟数据。在线 Demo、正式 Release 和独立 npm 包尚未发布。
- **实验后端**：`apps/py-api` 与 NestJS 默认路径并非功能等价，后续依据实际需求决定维护范围。
