# 评测任务可靠性验收

日期：2026-10-08。分支：agent-lab。RELEASE-READINESS-2 的评测子阶段。

已完成持久化排队、幂等提交、跨副本领取、进度与拒绝原因展示。以下为工程验证；真实版本质量对比仍未通过，本阶段没有启动付费业务评测或发布候选。

## 交付行为

POST 返回 `202`、任务 ID 和 `statusUrl`，后台复用既有运行与评测实现。必须提供 `requestKey`；相同键和请求复用任务，不同内容或 Agent 已有活动任务返回 `409`。历史同步记录不会进入新队列。

任务持久化 `PENDING → RUNNING → COMPLETED/FAILED`。资产指纹、ADMIN 重查、原子领取和心跳保护执行。过期只记失败，保留结果与费用小计，不自动重放付费请求。前端每两秒查询，显示计划/完成样本、费用证据和拒绝原因；切换条件清除旧比较。

## 影响与边界

架构详见 ADR 18。迁移 `20261008000000_evaluation_jobs` 为加性字段/索引，无新依赖。POST 从同步结果变为异步回执，旧客户端须同步升级；GET 保留历史读取。默认拒绝鉴权、ADMIN、组织及 ownership 仍生效；新增轮询及进度写入，没有取消或自动续跑。

未知在途费用不能精确结算；历史总数不补造。本阶段不证明质量提升、成本节约或商用生产验收。真实评测保持既有 `REJECT/RG-021`，13 个完成样本、0.069285 CNY 已知小计，中断费用未知。后续仍需认证/题库整合、可信 CI/文档、干净部署与浏览器验收；本报告不将后续工作记为完成。
