# 信息架构

最后更新：2026-11-18（源码路由核对，本机阶段）

> 当前资料准备重设计见 `docs/project/INTERVIEW_PREPARATION_REDESIGN.md`。下述 P0/P1 方向属于目标设计，不作为已实现或真实验收证明。

## 导航模型

导航应围绕训练闭环，而非普通 SaaS 分类。

| 区域 | 用户为什么需要 | P0 状态 |
| --- | --- | --- |
| 首页 | 看到当前准备度与唯一最优下一步。 | 新增，替代当前首页重心。 |
| 练习 | 开始完整模拟或单技能练习。 | P0。 |
| 面试记录 | 继续、复盘或比较面试尝试。 | 由现有列表演进。 |
| 技能 | 查看长期技能证据、趋势与置信度。 | 数据合同完成后进入 P0。 |
| 知识库 | 添加能提升训练质量的岗位相关材料。 | P1 面向候选人的能力；保留现有管理能力。 |
| 题库 | 治理题目覆盖度与质量。 | 管理员导向，保留现有路由。 |
| 报告 | 查看已完成的评价与面试回放。 | P0，独立于面试房间。 |
| 使用量 | 了解模型额度与估算成本。 | P0 设计，后端前置条件属于 P1。 |
| 资料准备 | 固定管理简历上传/已存摘要与目标岗位。 | 本机实现；真实模型上传质量待验。 |
| 账号设置 | 独立管理账号与收起的密码修改流程。 | 本机实现，认证规则未改。 |

当前移动主导航为首页、资料准备、练习、面试记录、训练；账号设置位于页头。管理员知识库与题库管理不进入候选人主导航。

## 核心实体与状态

```text
用户
  -> 当前目标岗位
     -> 简历版本 + 可选职位描述 + 岗位技能图谱
     -> 面试会话（完整模拟 | 技能练习）
        -> 评估证据
        -> 面试评价
     -> 候选人技能档案
     -> 训练计划 / 训练项
     -> 复面比较
```

上图是产品方向。当前已读取的实现包括 User、Milvus 简历摘要、TargetJob、Interview、报告及技能/训练模块；版本化简历档案、完整文件库和可比较成长结果不能由该图推断已实现。

## 路由方向

```text
/                         首页
/practice                 模式选择与技能练习
/interviews               面试尝试与进行中的会话
/interview/:id            仅面试房间
/reports/:interviewId     评价与回放
/skills                   技能档案与趋势
/knowledge                候选人知识集合（未来）
/question-bank            管理员题库治理
/usage                    额度与成本摘要
/prepare/resumes          上传、搜索和检查已读取简历摘要
/prepare/jobs             创建、编辑、切换目标岗位
/settings                 账号与登录安全
```

源码核对：AuthGate 内的候选路由为 `/`、`/practice`、`/interviews`、`/training`、`/settings`、`/prepare/resumes`、`/prepare/jobs`、`/reports/:id` 与独立面试房间 `/interview/:id`。`/prepare` 重定向简历页；`/question-bank`、`/admin/mcp` 重定向首页，`/tools` 重定向账号设置。上方 `/skills`、`/knowledge`、`/usage` 是未来方向，不是当前可达页面。Lab 管理能力属于独立入口。

## P0 信息规则

- 当前目标岗位必须成为一等上下文对象，而不是散落在 UI 查询参数中的字段。
- 报告属于已完成面试，必须在面试房间外打开。
- 技能详情必须展示分数、置信度、趋势、证据数量和最近评估时间。
- 每项训练推荐必须说明触发它的证据与能力缺口。
- Agent、RAG、MCP 和模型内部实现不进入候选人界面。
