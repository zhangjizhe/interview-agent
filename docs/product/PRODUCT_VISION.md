# 产品愿景

最后更新：2026-08-13

## 产品定义

Interview Agent 是 AI 面试训练产品，不是 AI 聊天页面。它服务于正在准备具体技术岗位的候选人，帮助用户明确下一步训练行动，并长期看见能力变化。

```text
目标岗位 -> 候选人证据 -> 模拟面试 -> 基于证据的评价
-> 能力缺口 -> 定向训练 -> 再次面试 -> 成长
```

产品不得暗示评分可以预测 Offer。评分只是在特定目标岗位与当前证据范围内的准备度估计。

## P0 用户结果

首次用户可以选择目标岗位、提供简历和可选 JD、完成一次面试、理解评价依据，并开始下一项推荐训练。回访用户可以从明确的下一步行动恢复闭环，并比较不同时间的证据变化。

## 产品原则

- 改进优先于聊天：对话是评估与训练的手段，不是导航模型。
- 证据优先于分数：每个分数都必须说明来源、置信度和推荐行动。
- 单一目标岗位：当前目标岗位决定题目、评价和训练的上下文。
- 渐进式承诺：个性化模拟面试需要简历；JD 和知识库是可选增强项，不应阻塞入门。
- 诚实呈现状态：未实现的能力不能显示为已完成，低证据结论必须明确标注。
- 安全地提供价值：所有模型调用必须经过带鉴权和策略控制的后端与 LLM Gateway。

## P0 范围

- 目标岗位设置与轻量 Onboarding。
- 以准备度、能力缺口、最近表现和下一步行动为中心的首页。
- 完整模拟面试与单技能练习。
- 分离面试、评价、复盘和重试模式。
- 基于证据的评价、技能档案、训练推荐、回放和进步对比。

第一个实现增量必须先建立对应数据合同，才能把上述能力作为长期用户能力展示。

## 明确非目标

- Offer 预测、自动招聘建议或不透明的候选人排序。
- 计费或支付实现。
- 团队协作、多租户或小程序。
- 向候选人暴露 Prompt、思维链、检索内部信息或工具执行细节。
- Agent 或 Prompt 的自主修改。
