# 商业化边界

最后更新：2026-08-13

## 价值先于计费

可商业化的核心是可证明的面试准备度和持续能力提升，而不是无限制的模型聊天。订阅和支付属于 P2。P0 只定义避免未来滥用和误导 UX 所需的产品边界。

## 未来权益

| 套餐 | 候选人价值 | 约束 |
| --- | --- | --- |
| Free | 有限完整模拟、基础评价、有限练习。 | 必须展示剩余额度和重置时间。 |
| Pro | 更多面试、技能历史、训练、回放、丰富报告、岗位/知识支持。 | 必须由服务端强制，不能由 UI 推断。 |

## 必需使用量台账

商业化 UI 之前，后端必须按用户和周期记录：

- `interview_count`
- `evaluation_count`
- `token_usage`
- `estimated_cost`
- `daily_usage`
- `monthly_usage`

现有 `SessionCost` 按面试追踪成本，但不提供用户权益强制或周期聚合。浏览器不得直接调用任何 LLM Provider。

## 隐私与信任

- 简历、JD、回答、证据和 Trace 可能包含敏感信息。
- 付费计划前必须明确保留、导出和删除行为。
- 使用量页面只展示聚合使用情况，不展示原始 Prompt 或 Provider 凭据。
