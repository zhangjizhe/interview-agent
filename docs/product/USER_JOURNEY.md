# 用户旅程

最后更新：2026-08-13

## 黄金路径：第一次面试

```text
注册或登录
-> 选择目标岗位和职级
-> 上传简历（必填）
-> 添加职位描述 JD（可选）
-> 审阅生成的岗位技能图
-> 开始完整模拟面试
-> 回答并接受自然追问
-> 完成面试
-> 查看基于证据的评价
-> 接受下一项推荐训练
-> 练习一个技能
-> 再次面试
-> 比较成长变化
```

### 页面级合同

| 步骤 | 用户目标 | 主操作 | 系统响应 | 退出条件 |
| --- | --- | --- | --- | --- |
| 岗位设置 | 定义准备目标 | 选择岗位和职级 | 创建/更新当前目标岗位 | 简历步骤 |
| 简历 | 提供个人面试证据 | 上传并确认解析摘要 | 解析并建立索引 | 可选 JD |
| JD | 添加岗位特定期待 | 粘贴/上传 JD，或跳过 | 提取岗位要求和覆盖度 | 技能图审阅 |
| 技能图审阅 | 理解准备基线 | 确认或编辑建议优先级 | 将岗位档案标记为就绪 | 完整模拟面试 |
| 面试 | 在面试条件下展示能力 | 提交回答 | 自然追问且不泄露评分 | 完成面试 |
| 评价 | 理解分数与缺失证据 | 查看分数、证据和建议 | 持久化评估与下一步 | 训练或回放 |
| 训练 | 关闭高影响缺口 | 开始定向训练 | 记录计划和完成情况 | 再次面试 |
| 比较 | 看到变化，而不只是新分数 | 比较同技能证据 | 展示分数变化和证据变化 | 新的下一步行动 |

## 回访与高频用户

| 状态 | 首页必须回答 | 默认下一步 |
| --- | --- | --- |
| 评价后回访 | 最薄弱的是什么？现在该做什么？ | 开始影响最大的定向训练。 |
| 有进行中面试的回访 | 是否可以不丢上下文地继续？ | 恢复这场面试。 |
| 训练后回访 | 缺口是否已缩小到值得再次测试？ | 开始可比较的复面。 |
| 高频练习 | 我反复缺少什么？ | 轮换至低置信度、最薄弱的技能。 |

## 必需边界状态

| 状态 | 产品行为 |
| --- | --- |
| 无简历 | 说明个性化模拟面试需要简历；仅在用户明确选择时允许通用岗位练习。 |
| 无 JD | 使用岗位基线继续；标记岗位档案为证据覆盖较低，不标记为数据不完整。 |
| 无知识集合 | 不阻塞训练；首次评价后推荐岗位相关知识。 |
| 首次面试未完成 | 保留会话并提供继续或放弃；证据不足时不生成评价。 |
| 低证据评价 | 展示分数置信度和证据数；在给出强结论前推荐一次定向补充评估。 |
| 额度已用尽 | 展示剩余额度、重置时间和非模型复盘操作。本能力仅完成设计，尚未实现。 |
