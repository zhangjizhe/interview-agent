# P0 页面规格

最后更新：2026-08-13

## 岗位设置

目的：明确本次准备所对齐的目标。

- 输入：岗位、职级、可选公司/JD、简历版本。
- 主操作：`分析准备情况`。
- 输出：按“简历已支持”“需要面试验证”“现有证据缺失”分组的技能覆盖。
- 空状态：无简历时说明无法进行个性化模拟；仅在用户明确选择时提供通用岗位练习。

## 首页

目的：一次浏览回答准备度、薄弱项、最近变化和下一步。

桌面布局：

```text
当前目标岗位 + 编辑
准备度估计 + 证据置信度 + 相对上一次可比评价的变化
技能概览                           最优下一步行动
前三能力缺口                       最近面试与趋势
```

- 准备度必须展示构成项及“系统估计”说明。
- 没有完成评价时，展示设置进度和 `开始第一次完整模拟面试`。
- 不得用 Token 或面试次数推导准备度。

## 练习

目的：让用户有意识地选择练习模式。

- 完整模拟面试：使用当前目标岗位，并按岗位优先级混合技能。
- 单技能练习：用户选择一个技能，默认推荐影响最大且已有评估的缺口。
- P0 不包含弱项专项和快速练习，直到其模式、时长与评分合同被持久化。

## 面试房间

目的：模拟结构化面试，不暴露内部编排。

- 头部：岗位、职级、模式、题目进度、当前技能、难度、可选计时。
- 主区域：单个问题、自然追问历史和回答编辑器。
- 控制：提交回答、结束面试、稍后继续。
- 完成：显示生成评价的过渡状态，再进入报告。
- 禁止：在完整模拟模式中显示 Prompt、思维链、模型名、RAG Chunk、工具日志、Token 计数、原始 Trace ID 或即时答题分数。

## 评价与回放

目的：解释结果，并引导可衡量的重试。

- 摘要：准备度估计、总体评价分数、置信度，以及相对最近可比尝试的对比。
- 技能拆解：分数、证据数量、置信度、趋势和一项具体未满足期待。
- 证据卡片：问题摘要、候选人回答摘要、评估理由、期待证据和建议重试方式。
- 推荐练习：一项带技能、时长和优先级理由的行动。
- 回放：按问题、回答、追问和评价顺序展示。`再试一次` 必须创建关联的新尝试，不能覆盖历史。

## 技能

目的：让长期评估清晰且可证伪。

每行技能信息：

```text
分数 | 置信度 | 趋势 | 证据数量 | 最近评估 | 打开证据
```

没有持久化评估证据的技能不得显示分数。低置信度分数需要更多评估，不应生成强训练结论。

## 训练

目的：关闭一个能力缺口，并回到可比测试。

P0 从单张定向训练卡开始：

```text
技能 -> 目标 -> 1-3 个练习提示 -> 期待证据 -> 复面触发条件
```

多日周训练计划只在进度和完成合同实现后进入产品。

## 响应式规则

- 桌面：固定分区导航和双列决策布局。
- 平板：收起侧栏，面试上下文保留在紧凑头部。
- 移动端：首页、练习、技能和报告为主导航；回答编辑器固定，进度持续可见，详细证据在独立视图打开。
