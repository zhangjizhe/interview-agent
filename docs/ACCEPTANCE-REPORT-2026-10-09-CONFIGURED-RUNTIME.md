状态：阶段工程验证通过，整体产品 NOT_ACCEPTED；本阶段未进行真实外部模型质量评测。

## 功能与边界

新增原子创建 Agent 和初始草稿、固定版本配置、单 Agent 与最多10节点的无环工作流；支持顺序、回答包含条件分支、原始输入或前节点输出映射。草稿测试不会发布；依赖配置指纹固定，发布前要求依赖全部已发布。工具、知识和记忆绑定暂未开放，API明确拒绝，不忽略配置。

执行经统一模型网关，每节点最多一次调用，无 fallback、无 SDK 重试。调用前检查估算预算，未知定价阻止调用；执行后保留 usage 和费用证据，未知费用不计零。时限在调用边界检查，取消不能撤回在途请求。队列通过请求指纹去重、工作区单活跃任务、租约及终态 CAS 避免重复执行和晚到结果覆盖；失联任务失败且不自动重放。旧同步入口拒绝配置 Agent，内部受控评测仍可执行草稿。

数据库新增5个可空运行字段及请求唯一、状态心跳、工作区单活跃任务索引，兼容历史运行。新增配置/模型查询、草稿测试、生产运行排队和取消 API，沿用 ADMIN 和租户边界，执行前重新核验当前角色。既有用户权限不变。
