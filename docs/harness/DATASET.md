# 评估数据集

最后更新：2026-08-13

## 当前数据集

`apps/api/src/evals/golden-dataset.json` 当前为 `1.0.0`，包含 30 个 Case、60 个回答，覆盖前端和 AI Agent 岗位。它标注预期分数、评分维度、反馈关键词和人工理由，是评估器基线，但不是完整的面试 Agent 数据集。

## 数据集扩展

维护相互独立、带版本的切片：

| 切片 | 目的 |
| --- | --- |
| Evaluator Golden | 用人工参考验证分数、维度和反馈。 |
| Question Selection | 验证岗位/技能/难度选择与重复题规避。 |
| Follow-up | 验证候选人回答后的相关性、深度和非重复追问。 |
| Evidence Extraction | 验证期待/观察证据与技能归属。 |
| Adversarial | 测试注入、无依据断言、私密数据泄漏和不安全检索。 |

每个 Case 都要包含来源、责任人、审查日期、分类标签、允许用途和脱敏内容。生产对话样本必须经过同意、脱敏和保留策略审查。
