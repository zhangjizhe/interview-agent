# 评估器校验

最后更新：2026-08-13

## 现有指标

当前 Golden Evaluator 计算分数 Pearson 相关系数、分数 MAE、档位准确率、关键词命中率、样本数和模型调用错误。

## 所需指标

在将评估器结果写入技能状态前，增加以下可审查指标：

- 按岗位、技能、难度和回答质量档位统计的人类/评估器一致性；
- 对“缺失期待证据”的假阳性和假阴性；
- 过度评分与过低评分分布；
- 证据精确度：引用的证据必须真实出现于回答；
- 技能归属一致性；
- 结构化输出有效率、延迟、Token 和估算成本。

## 校准

人工参考标注是评估数据集的权威。模型评估器可以辅助分流，但不能作为自身的 Ground Truth。校准变更必须包含数据集版本、规则版本、评估器版本、对比运行和发布决策。
