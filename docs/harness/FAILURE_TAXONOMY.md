# 失败分类

最后更新：2026-08-13

每个失败可附一个或多个标签。所有标签必须保留原始证据和评估器版本。

| 标签 | 定义 |
| --- | --- |
| `WRONG_QUESTION` | 题目不符合目标岗位、职级或选定技能。 |
| `BAD_FOLLOWUP` | 追问忽略回答、缺少诊断价值，或对候选人有诱导性。 |
| `MISSING_EVIDENCE` | 评价在没有回答或来源证据时作出断言。 |
| `HALLUCINATION` | Agent 声称没有依据的事实、期待或候选人结论。 |
| `CONTEXT_MISS` | 可用的简历/JD/会话上下文相关，但未被使用。 |
| `MEMORY_MISS` | 策略允许时，相关长期用户上下文未被召回。 |
| `RAG_MISS` | 检索未提供相关且已授权的来源材料。 |
| `DIFFICULTY_MISMATCH` | 题目难度不适配当前目标或证据。 |
| `REPETITIVE` | 没有训练理由时，重复实质相同的题目或追问。 |
| `OVER_SCORING` | 分数显著高于已校准的人类参考。 |
| `UNDER_SCORING` | 分数显著低于已校准的人类参考。 |
| `WRONG_SKILL` | 题目或证据归属到错误技能/子技能。 |

失败分类是审计工具，不是自动根因结论。
