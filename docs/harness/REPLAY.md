# 回放

最后更新：2026-08-13

## 候选人回放

候选人回放按以下顺序展示已完成尝试：

```text
问题 -> 回答 -> 追问 -> 评价 -> 证据 -> 重试
```

重试必须创建关联且不可变的新尝试。只有技能、评价规则和难度可比时，才能比较分数与证据。

## 工程回放

工程回放通过指定 Agent 版本重新运行已脱敏的 Trace 输入，并对比：

- 选题和追问；
- 结构化评价和证据；
- 延迟、Token、成本、错误与失败标签。

现有 Trace 和 checkpoint 是有价值的调试资产，但尚无回放/版本对比产品合同。工程 Trace 不得暴露给候选人。
