SMTP uses Nodemailer with STARTTLS or implicit TLS; each purpose has a distinct email label. Failures remove the challenge and logs omit mailbox/code. An occupied registration email returns a same-shaped synthetic challenge without sending mail.

Existing accounts become unverified. An owner who remembers the current password may claim and verify a mailbox. If the old password is forgotten and no mailbox was verified, self-service recovery is intentionally unavailable; a separately verified support/admin recovery process remains unresolved.
