# 题库交互修整

2026-11-10。用户在历史资料读取恢复后继续要求改善上传、主题、按钮及整体交互。本轮唯一主题为题库日常操作体验，保留 Trace 与资料恢复的前序候选，不扩展未验收的数据治理/schema/runtime。

## 设计与源码核对

- 实际入口为 Agent Lab `ControlCenter` → `QuestionBankWorkspace`。旧 Web `QuestionBankPage` 已不在可达路由；不能修改旧页后声称 Lab 上传已恢复。
- 旧页面存在选择文件即提交、假拖拽说明、JSON类型承诺与当前解析链不符、岗位/主题混用。Lab缺导入入口，迁移优先于日常工作、按钮缺主次。原存储问题及142历史资料见 QUESTION_BANK_READ_RECOVERY。
- 参考公开官方规则：Carbon File uploader（选择/上传/错误状态与真实可用格式）；Atlassian Button（每个操作区单一主操作）。本轮只借鉴模式，复用现有React/Lucide/CSS，不安装UI框架、不复制品牌。
- 来源：https://v10.carbondesignsystem.com/components/file-uploader/usage/ 、https://atlassian.design/components/button/usage/ ，2026-11-10读取。

## 实现与影响

- `QuestionImportPanel`：文件/URL来源切换，支持实际拖拽；仅PDF/MD/TXT、单文件10MB、空文件/格式/URL本地校验。选择后显示文件信息，不自动上传。
- 显式目标岗位、题目主题（对应category）与职级字段；提交前说明模型费用、最多20题及长文前段限制。字段错误聚焦并标记aria-invalid，说明文字独立关联。原文存储不伪称通用RAG。
- 显式开始导入；提交ref防重复、pending禁用控件、刷新提示、切换资料源/侧栏禁用。190秒上限仅结束客户端等待，不声称取消后端。失败/回执异常保留输入并锁住提交；人工核对后仍须重新确认模型处理。
- 校验success/count/唯一IDs/CATALOG持久化与索引回执；0题不写成功新增，SAVED/PENDING不重复导入；可继续下一份资料。收起导入保留本页面草稿，不承诺跨刷新/退出恢复。
- `QuestionBankWorkspace` 统一操作层级、过滤区、加载条数、答案折叠、删除按钮可访问名称、表单间距和移动排版。原主数据保存/删除回执断言保留。移除UI中无法代表整个操作总费用的固定单请求价格说明。
- `main` 将高级存储/索引维护折叠在业务列表后，日常上传优先。样式只作用题库区域；未做全平台重写。
- 复用既有ADMIN、可信组织和Interview导入API；无新增表/API/权限/模型实现，不发布Agent、不迁移数据。API启动导入可能付费，因此本轮只换前端，未重启API。
