# 项目路线图

最后更新：2026-08-13
战略来源：`docs/product/PRODUCT_ROADMAP.md`。本文件仅保留优先级层次。

## P0：保护现有产品基础

- 保持默认 NestJS 产品路径可构建、有鉴权、资源隔离安全，并可复现测试。
- 当改动涉及相关路径时，保留基于真实 Provider、浏览器和 API 的验收证据。
- 在宣称质量改进前建立受控 Agent Evaluation 闭环。

## P1：完成面试训练闭环

- 围绕目标岗位、准备、面试、评价、能力缺口、定向训练、复面与成长定义产品信息架构。
- 将结构化面试评价转换为持久化技能档案和趋势数据。
- 从已证明的缺口生成训练计划，并验证用户结果。
- 改善知识与题目智能，但不向用户暴露 RAG 实现复杂度。

## P2：SaaS 与多端扩展

- 在稳定价值闭环后新增 Usage Ledger、Quota、Entitlement 和 Billing。
- 增加 Agent/Prompt 的实验与版本运营能力。
- 通过共享 API Contract 支持 Web 和面向日常训练的移动端/小程序。
- 仅在产品需求明确时引入租户隔离和规模化运维。
